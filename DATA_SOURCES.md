## Source handling

- `scripts/source_checksums.py` prints the exact staged-file fingerprints.
- `scripts/audit_sources.py` reports archive structure, table schemas, row counts, and missingness to `reports/private/source-audit.json`. It does not emit table rows or read Word interview-transcript content.
- `scripts/run_available.py --project all` reads public source archives in memory. It does not extract raw archives or write participant-level derived files.
- Aggregate estimates are written under `runs/latest/`, which is ignored by Git. Do not publish raw files, interview text, source IDs, or unredacted open answers as part of a manuscript supplement.
- Public availability is not a blanket license. Check each repository's reuse terms and participant consent before redistributing any source material.
