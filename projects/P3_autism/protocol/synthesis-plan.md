# P3 synthesis plan — working draft

## Core question

How do autism–mental-imagery estimates vary across autism ascertainment, imagery instrument/threshold, and recruitment frame? Separate diagnosis-group contrasts from within-group dimensional AQ/CATI associations. The reanalysis of Arnold alone is a source-reproduction exercise, not the main manuscript contribution.

## Eligibility and extraction

Include adult human studies with same-person imagery and autism diagnosis/trait data, including null findings. Exclude case reports from quantitative synthesis; keep pediatric samples separate. Extract the source fields in `templates/study-compatibility-matrix.csv`. Record explicit absence and each study's low-imagery rule separately; never force different instruments onto one universal threshold. Record comparator source and known overlap before counting independent cohorts.

## Effect estimates

For each cohort, report source-compatible group differences and strict-absence prevalence contrasts. Estimate imagery–AQ/CATI slopes only where those traits were actually administered, retaining each eligible sample frame. Keep the current Arnold AQ≥26-selected group as a sensitivity to the full self-reported-diagnosis group; its controls overlap and it is not an independent sample.

Display every eligible study estimate. Pool only within a construct, instrument, and recruitment stratum with at least three independent comparable cohorts; otherwise show study-specific estimates without a pooled headline. If overlap cannot be resolved, use alternate inclusion sensitivities or report cohorts separately. Use aggregate results if participant-level data are not obtained; nonresponse does not remove a null study.

## Open gates

1. Verify Arnold workbook-to-code mapping and the earlier control cohort's origin.
2. Log the existing user-reported Dance autism-data request and await its reply; do not duplicate it.
3. Complete database searches, deduplicate, and screen before final eligibility claims.
4. Request Taylor/King/Bouyer data only after confirming instrument compatibility and a specific added contribution.
5. Register the synthesis methods after search eligibility and data status are known, with prior findings disclosed.
