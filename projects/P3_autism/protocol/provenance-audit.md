# P3 provenance gate

The current P3 result is an Arnold et al. (2026) anchor reanalysis. It is not yet a cross-study autism result because two provenance questions remain open.

| Item | Current evidence | Required resolution before synthesis |
|---|---|---|
| Formal autism group | The published MATLAB analysis archive contains 327 diagnosed participants; the local code parser reproduces that group and 327 comparison participants. | Reconcile the code arrays with the public workbook's row/column labels and exclusions. |
| Comparison cohort | The 327 controls are represented in the analysis file, but their earlier-study recruitment source is not established in the local documentation. | Identify the source cohort, recruitment frame, instrument version, and any participant overlap with Arnold's diagnosed sample or other candidate studies. |
| AQ≥26 sensitivity | The authors' code selects 242 of the 327 diagnosed participants at AQ ≥ 26 while retaining the same 327 controls. | Keep this as a sensitivity only; never count it as an independent cohort. |
| Dance autism experiment | The user reports already requesting the separate autism-study data from the author. | Record the sent date and response from the user's correspondence; do not send a duplicate request. The public `h24vm` OSF archive is a different imagery × sensory-sensitivity auxiliary dataset. |

Until these checks are resolved, describe the P3 output as a source-linked anchor and infrastructure for a future synthesis. The repeated-modality stress tests are useful for assessing robustness within this dataset, but they do not substitute for an independent cohort.
