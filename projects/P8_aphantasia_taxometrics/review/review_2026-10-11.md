## Cold-read review (11 Oct 2026)

**Verdict: fix before registering.** The writing is plain and clear. The methods have one real hole and several gaps, listed below with what I plan to do about each.

### Methods

| # | Problem | Planned fix |
|---|---|---|
| 1 | **The floor can fake two groups.** Many website respondents score the minimum (16), so they are at the floor on all four scene scores at once. The package's simulated continuous data copy each indicator's floor separately, but not a block of people at the floor on all four together; the simulated two-group data do. A continuum with a floor could therefore look like two groups. | Report how many people are at the floor. Add a planned check: simulate a continuum with the same floor (one underlying factor, item cut-points matched to the real item distributions, same n) and run it through the same pipeline. If that fake continuum also reads as "two groups", we say a two-group result cannot be told apart from a floor effect. |
| 2 | **Ties shift the group size.** When the cut falls inside a block of identical scores, the whole block goes to one side, so the actual group size can differ from the one requested. | Report the group size actually used, and say in the plan that ties are handled this way. |
| 3 | **The population-matched check will rarely say "two groups".** After matching, the possible group is about 4%, below the ~10% the method needs, and score bands with no Dance cases (likely 16–19) drop out, removing the floor block. As written, a two-group conclusion is nearly impossible. | Say plainly that this check can only weaken a two-group result, and report its expected size. Add a simulation: a known two-group population, selected the way the website was, then matched, to show whether the check can still detect it. |
| 4 | **Correlations within each group will be high** (scene scores are parts of one questionnaire), well above the 0.30 guide. | Add a planned rule for lowering trust when they are high, and list it as a limitation. |
| 5 | **Picking the group size from the profile pushes the main fit score up**, because it is the size that gave the best fit. | Make the profile's own fit score the main evidence, with the cut-off-32 run reported alongside it. |
| 6 | **Missing decision rules** for when the three procedures, the two halves, or the robustness checks disagree; and which number answers "how large is the group". | Add these rules to §6. |
| 7 | **Question 3 does not match its definition.** "At least one sense at the floor" is an any-sense group; the question asks about low imagery in all senses. | Reword question 3 to match. |
