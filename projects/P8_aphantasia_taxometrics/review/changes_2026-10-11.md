## What changed after the review

| Review point | Change |
|---|---|
| The floor can fake a taxon | New **floor check** (§5.4): a simulated continuum with the same floor goes through the same steps. If it also reads as a taxon, the conclusion is "cannot tell a taxon from a floor effect" (§6). The number of people at the floor is reported. |
| Ties shift the group size | The share actually used is reported next to the share asked for (§4.2). |
| The matched check can rarely say "taxon" | The plan now says it can only weaken a taxon result (§3.2). A new **detectability check** (§5.4) shows whether it could detect a taxon of that size at all. |
| High within-group correlations | A result is called **lower-trust** if separation is weak *or* within-group correlations average above 0.30; full correlation tables are reported (§5.1). Listed as a limitation. |
| Best-fit group size inflates the score | The provisional taxon share is now fixed at the share with a VVIQ of 32 or below (§4.2). The main result needs **both** the main CCFI and the profile's CCFI to agree (§6). |
| Missing decision rules | §6 now has an ordered rule table covering the floor check, the two halves and the matched subsample, plus what is reported without changing the conclusion. Question 2 uses the profile's size estimate. |
| Question 3 mismatch | Now "low imagery across several senses", with the provisional taxon defined as four or more of the eight senses at the floor. |
| Plan versus code | The code now checks all three data files' SHA-256 and required columns, reports each survey's n, computes the lower-trust flag, and keeps undefined correlations visible. Seeds and file names are stated in the plan. |
| Writing | MAMBAC, MAXEIG, L-Mode and the CCFI profile are explained in plain sentences; "taxon" and "provisional taxon" are used throughout; the broken §6.3 reference is fixed; the "continuum" reading no longer overclaims; the Monzel et al. description now says five *ways of defining* aphantasia. |

Also checked in the package source: how the CCFI profile's summary score and size estimate are calculated (§5.2 describes both), and how ties are handled.
