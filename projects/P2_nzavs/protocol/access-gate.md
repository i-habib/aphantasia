# P2 access and analysis gate

P2 cannot start participant-level analysis until NZAVS agrees to the new project, the required institutional/sponsor route is in place, and an approved linked extract is provided.

## Exact feasibility request

Ask the NZAVS team to confirm whether the same participants have T13 visual imagery, T13 auditory imagery, T13 K6 distress, and T14 K6 distress. Ask for available T13/T14 Personal Wellbeing Index fields as secondary outcomes, plus matched retention counts overall and for the no-visual-imagery response group. Also ask about T12 baseline-history and T15 later outcomes only as optional extensions.

## Go/no-go

Proceed only if panel linkage permits baseline-outcome adjustment, the T13/T14 outcome is available for enough retained participants, the no-imagery group is not lost through attrition, and the study team confirms no conflicting planned analysis. No response or access approval is assumed. Track all contact in the root `request-tracker.csv`; Codex has not sent a request.

## Planned analysis after approval

Primary: T14 K6 predicted by T13 visual imagery and T13 K6, with a small prespecified confounder set and survey design handled according to the custodian's guidance. Treat full imagery response as primary and the no-imagery group as secondary. Add auditory imagery as a prespecified competing modality. Report attrition, weighting, missingness, and sensitivity to follow-up selection. Do not make causal claims or use imagery as a diagnostic screen.
