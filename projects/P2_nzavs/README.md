# P2 — NZAVS longitudinal imagery and distress

**State:** access-dependent; no participant data are present and no model can run yet.

## Proposed question

Does Time 13 visual imagery predict Time 14 psychological distress after accounting for the same distress outcome at Time 13? Auditory imagery and wellbeing are prespecified secondary measures. The target is a prospective conditional association, not a causal effect.

## Access package

- Read [`nzavs-concept-proposal.md`](../../nzavs-concept-proposal.md) and the NZAVS request in [`data-request-drafts.md`](../../data-request-drafts.md).
- Track correspondence in [`request-tracker.csv`](../../request-tracker.csv).
- Confirm collaboration, sponsor, governance, imagery/outcome field coverage, matched-wave retention counts, and overlap with work already planned by the NZAVS team before requesting a linked extract.
- Do not send a request until identity and affiliation fields are truthful and complete.

## Required fields and go/no-go

Request anonymized panel linkage; T13 visual and auditory imagery; T13 and T14 K6 distress; T13 and T14 wellbeing for secondary analyses; age and recorded gender; survey weights; wave timing; missingness and retention flags. Confirm counts overall and among respondents selecting no visual imagery. Proceed only when the same respondents can be linked across the required waves and the study team approves the question and use.

No pipeline is enabled for NZAVS yet. When an approved extract is received, add its data contract and code only after its permitted storage and analysis conditions are documented.
