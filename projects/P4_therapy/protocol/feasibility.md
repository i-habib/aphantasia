# P4 feasibility decision

**Decision: stopped.** The current Mawtus public quantitative file cannot identify the proposed auditory-capacity × auditory-therapy-use association with modality-specific effectiveness.

The data have a participant-level overall treatment-effectiveness field and modality-involvement questions, but most modality fields do not explicitly identify both use and non-use. The auditory field has one observed nonblank level in 302 records. No per-modality effectiveness outcome was identified. The original paper already compares broad therapy categories.

No inferential P4 model should be run from these fields. Reopen only when a permitted dataset links each treatment record's explicit modalities and effectiveness outcome, gives a defensible repeated-treatment unit, and measures relevant imagery capacity with adequate overlap. Never copy an overall effectiveness rating onto several modality records.
